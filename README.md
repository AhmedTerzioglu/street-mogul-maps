# Street Mogul — map packs

Province/state map packs (`.mrp`) used by the iOS game **Street Mogul / Sokağın Reisi**.
Each country is a release tagged with its ISO 3166-1 code (e.g. `US`), containing `<CC>.prov.json`
(province list and simplified boundaries) and one `<ISO 3166-2>.mrp` file per province/state.
